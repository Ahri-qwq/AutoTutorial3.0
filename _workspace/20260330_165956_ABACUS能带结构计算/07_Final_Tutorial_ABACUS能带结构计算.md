# 第一章：认识能带结构

## 1.1 从Si说起

硅（Si）是现代半导体工业的基石。从计算机芯片到太阳能电池，Si的应用无处不在。Si之所以如此重要，关键在于它的电子能带结构——Si是一种间接带隙半导体，带隙约1.17 eV，这使得它既能导电又能控制电流。

要理解Si的电学性质，就必须计算它的能带结构。本教程将带您使用ABACUS计算Si的能带图，揭示其间接带隙的特征。

## 1.2 什么是能带结构

### 能带的物理意义

能带结构描述了晶体中电子的能量-动量关系，即电子在不同k点（倒空间中的波矢）的能量分布。

在孤立原子中，电子占据分立的能级。当原子组成晶体后，原子间的相互作用使得这些分立能级展宽成能带。电子在晶体中的运动受到周期性势场的约束，其能量形成一系列允许的能带和禁止的带隙。

**关键概念**：
- **价带（Valence Band）**：被电子占据的最高能带
- **导带（Conduction Band）**：未被占据的最低能带
- **带隙（Band Gap）**：价带顶与导带底之间的能量差
- **费米能级（Fermi Level, Ef）**：绝对零度时电子占据的最高能级

### 金属、半导体、绝缘体

根据能带结构，材料可分为三类：

**金属**：
- 费米能级位于导带中
- 价带与导带重叠或部分填充
- 电子可自由移动，导电性好

**半导体**：
- 价带与导带之间有较小的带隙（0.1-3 eV）
- 费米能级位于带隙中
- 室温下少量电子可跃迁到导带
- Si的带隙：1.17 eV（实验值，300K）

**绝缘体**：
- 价带与导带之间有较大的带隙（>3 eV）
- 费米能级位于带隙中
- 电子难以跃迁，几乎不导电


## 1.3 直接带隙与间接带隙

带隙不仅有大小之分，还有类型之分。

### 直接带隙

价带顶和导带底位于同一k点。电子从价带跃迁到导带时，动量不变，只需吸收或发射光子。

**特点**：
- 光吸收/发射效率高
- 适合制作发光器件（LED、激光器）
- 典型材料：GaAs、InP

### 间接带隙

价带顶和导带底位于不同k点。电子跃迁时需要同时改变能量和动量，必须借助声子参与。

**特点**：
- 光吸收/发射效率低
- 不适合制作发光器件
- 适合制作电子器件
- 典型材料：Si、Ge

### Si的间接带隙特征

Si是典型的间接带隙半导体：
- **价带顶**：位于Γ点（布里渊区中心）
- **导带底**：位于X点附近（约0.85倍X点位置）
- **带隙值**：1.17 eV（实验值，300K）

这就是为什么Si芯片不发光，而GaAs可以做成LED。


## 1.4 DFT能带计算方法

### 两步法：SCF + NSCF

使用DFT计算能带结构需要两个步骤：

**第一步：自洽计算（SCF, Self-Consistent Field）**
- 目的：获得收敛的电荷密度
- 方法：在密集的k点网格上迭代求解Kohn-Sham方程
- 输出：电荷密度文件（SPIN1_CHG.cube）

**第二步：非自洽计算（NSCF, Non-Self-Consistent Field）**
- 目的：计算高对称路径上的能带
- 方法：固定电荷密度，在指定k点路径上求解本征值
- 输出：能带数据文件（BANDS_1.dat）

### 为什么需要两步

能带结构需要在布里渊区的高对称路径上密集采样，但SCF收敛只需要均匀的k点网格。如果在高对称路径上做SCF，会浪费大量计算资源且难以收敛。

两步法的优势：
- SCF使用均匀网格，收敛快
- NSCF使用路径采样，只需一次对角化
- 总计算量远小于直接在路径上做SCF

### DFT带隙的局限性

**PBE泛函低估带隙**：
- Si实验带隙：1.17 eV（300K）
- Si的PBE带隙：~0.57 eV
- 低估约50%

**原因**：
- PBE等GGA泛函存在自相互作用误差
- 低估了激发态能量

**改进方法**：
- 杂化泛函（HSE06）：计算量大，带隙接近实验值
- GW近似：更精确但计算成本极高
- 本教程使用PBE，重点在于流程和方法

尽管PBE低估带隙，但能带的形状和色散关系仍然可靠，足以用于定性分析和方法学习。

# 第二章：Si体系准备

## 2.1 Si的晶体结构

### 金刚石结构

Si采用金刚石结构，这是一种面心立方（FCC）结构的变体。每个Si原子与4个最近邻原子形成共价键，键角109.5°（四面体角）。

**晶格参数**：
- 晶格常数：a = 5.43 Å（实验值，室温）
- 空间群：Fd-3m（No. 227）
- 原胞：2个Si原子
- 常规晶胞：8个Si原子

本教程使用8原子的常规晶胞，便于理解和可视化。

### 原子坐标

在立方晶胞中，8个Si原子的分数坐标为：
```
(0.00, 0.00, 0.00)  (0.25, 0.25, 0.25)
(0.00, 0.50, 0.50)  (0.25, 0.75, 0.75)
(0.50, 0.00, 0.50)  (0.75, 0.25, 0.75)
(0.50, 0.50, 0.00)  (0.75, 0.75, 0.25)
```

这8个原子构成了Si的金刚石结构。

# 第三章：SCF自洽计算

## 3.1 SCF的作用

自洽计算（SCF）是能带计算的第一步，其核心目标是获得收敛的电荷密度。

### 为什么需要SCF

在DFT中，电子的哈密顿量依赖于电荷密度，而电荷密度又由电子波函数决定。这形成了一个自洽问题：
1. 给定初始电荷密度
2. 构建哈密顿量
3. 求解本征值和本征态
4. 计算新的电荷密度
5. 重复2-4直到收敛

收敛的电荷密度是体系的基态电荷分布，是后续NSCF计算的基础。

### SCF与NSCF的区别

| 项目 | SCF | NSCF |
|------|-----|------|
| 目的 | 获得收敛电荷密度 | 计算能带 |
| 电荷密度 | 迭代更新 | 固定不变 |
| k点采样 | 均匀MP网格 | 高对称路径 |
| 计算量 | 多次迭代 | 单次对角化 |
| 输出 | SPIN1_CHG.cube | BANDS_1.dat |


## 3.2 INPUT_scf文件

以下是Si的SCF计算INPUT文件：

```
INPUT_PARAMETERS

# 系统设置
suffix              Si
calculation         scf
pseudo_dir          ./
ntype               1
nbands              26

# 平面波参数
basis_type          pw
ecutwfc             40.0
pw_diag_nmax        20
pw_diag_ndim        2

# SCF收敛参数
scf_thr             1e-08
scf_nmax            100
mixing_type         broyden
mixing_beta         0.8

# K点求解器
ks_solver           dav_subspace
smearing_method     gauss
smearing_sigma      0.015

# 输出设置
out_chg             1
```


**关键参数说明**：

**系统设置**：
- `suffix = Si`：输出目录名为 OUT.Si
- `calculation = scf`：自洽计算
- `pseudo_dir = ./`：赝势文件所在目录
- `ntype = 1`：元素种类数（只有Si）
- `nbands = 26`：能带数量（Si有4个价电子，8个原子共32个价电子，占据16条能带，26条足够）

**平面波参数**：
- `basis_type = pw`：使用平面波基组
- `ecutwfc = 40.0`：截断能（单位：Ry）
- `pw_diag_nmax = 20`：对角化最大迭代次数
- `pw_diag_ndim = 2`：Davidson算法的子空间维度

**SCF收敛参数**：
- `scf_thr = 1e-08`：电荷密度收敛阈值（单位：无量纲）
- `scf_nmax = 100`：最大SCF迭代次数
- `mixing_type = broyden`：电荷密度混合方法（Broyden方法，收敛快）
- `mixing_beta = 0.8`：混合系数（0-1之间，越大收敛越快但可能不稳定）

**K点求解器**：
- `ks_solver = dav_subspace`：Davidson子空间对角化方法
- `smearing_method = gauss`：高斯展宽（处理费米面附近的占据）
- `smearing_sigma = 0.015`：展宽宽度（单位：Ry）

**输出设置**：
- `out_chg = 1`：输出电荷密度文件（二进制+cube格式）


## 3.3 KPT_scf文件

SCF计算需要密集的k点网格以准确积分布里渊区：

- 12×12×12对Si是合理的选择（共约864个约化k点）

# 第四章：NSCF能带计算

## 4.1 高对称路径的选择

### 布里渊区与高对称点

能带结构需要沿布里渊区的高对称路径计算。高对称点是布里渊区中具有特殊对称性的k点，能带在这些点附近通常有极值或特殊特征。

### Si金刚石结构的布里渊区

Si采用面心立方（FCC）晶格，其倒空间布里渊区是截角八面体。

**主要高对称点**：
- **Γ (Gamma)**：布里渊区中心，坐标 (0, 0, 0)
- **X**：立方边中点，坐标 (0.5, 0, 0.5)
- **L**：立方体顶点方向，坐标 (0.5, 0.5, 0.5)
- **K**：六边形面中心，坐标 (0.375, 0.375, 0.75)
- **U**：六边形边中点，坐标 (0.625, 0.25, 0.625)
- **W**：立方边与六边形面交点，坐标 (0.5, 0.25, 0.75)

### Si的标准高对称路径

根据文献（Setyawan & Curtarolo, Comp. Mater. Sci. 2010），Si的标准能带路径为：

**L → Γ → X → U,K → Γ**

这条路径覆盖了Si能带的关键特征：
- **Γ点**：价带顶
- **X点附近**：导带底（约0.85倍X点位置）
- **L点**：次高价带


## 4.2 INPUT_nscf文件

以下是NSCF计算的INPUT文件：

```
INPUT_PARAMETERS

# 系统设置
suffix              Si
calculation         nscf
pseudo_dir          ./
ntype               1
nbands              26

# 平面波参数
basis_type          pw
ecutwfc             40.0
pw_diag_nmax        20
pw_diag_ndim        2

# NSCF特殊设置
symmetry            0
init_chg            file

# SCF收敛参数（NSCF只迭代一次）
scf_thr             1e-08
scf_nmax            100
mixing_type         broyden
mixing_beta         0.8

# K点求解器
ks_solver           dav_subspace
smearing_method     gauss
smearing_sigma      0.015

# 输出设置
out_band            1
```


**与SCF的关键区别**：

**NSCF特殊设置**：
- `calculation = nscf`：非自洽计算
- `symmetry = 0`：**必须关闭对称性**（Line模式KPT要求）
- `init_chg = file`：读取SCF的电荷密度文件

**为什么symmetry必须设为0**：
- Line模式的k点路径是手动指定的，不遵循对称性
- 如果开启对称性，程序会尝试对k点进行对称操作，导致错误
- SCF可以使用`symmetry = 1`利用对称性加速，但NSCF不行

**输出设置**：
- `out_band = 1`：输出能带文件BANDS_1.dat
- 不需要`out_chg`（不更新电荷密度）

**电荷密度读取**：
- NSCF会自动在`OUT.Si/`目录查找`SPIN1_CHG.cube`
- 如果电荷密度文件在其他位置，需要设置`read_file_dir`参数

## 4.3 KPT_nscf文件

NSCF使用Line模式，沿高对称路径采样：

```
K_POINTS
6
Line
0.500  0.500  0.500  50  # L
0.000  0.000  0.000  50  # Γ
0.500  0.000  0.500  50  # X
0.625  0.250  0.625  20  # U
0.375  0.375  0.750  50  # K
0.000  0.000  0.000  1   # Γ
```

**参数说明**：
- 第1行：关键词
- 第2行：高对称点数量（6个）
- 第3行：Line模式
- 第4行起：每行为一个高对称点
  - 前3个数：k点的分数坐标
  - 第4个数：到下一个点的插值数
  - 注释：高对称点标记

**插值数选择**：
- L→Γ：50个点（较长路径）
- Γ→X：50个点
- X→U：20个点（较短路径）
- U→K：50个点
- K→Γ：1个点（终点，不插值）

插值数越多，能带曲线越光滑，但计算量越大。50个点是常用选择。

## 4.4 运行NSCF计算

**运行命令**：
```bash
cp INPUT_nscf INPUT
cp KPT_nscf KPT
mpirun -np 8 abacus | tee nscf.log
```

**注意事项**：
- 确保SCF已完成，`OUT.Si/SPIN1_CHG.cube`存在
- NSCF只需一次迭代，速度很快（通常几分钟）

**输出文件**：
- `OUT.Si/BANDS_1.dat`：能带数据文件
- `OUT.Si/running_nscf.log`：运行日志

## 4.5 BANDS_1.dat文件格式

能带数据保存在`BANDS_1.dat`中，格式如下：

```
1    0.0000    -5.234  -5.234  -3.123  -3.123  ...
2    0.0234    -5.230  -5.230  -3.120  -3.120  ...
3    0.0468    -5.218  -5.218  -3.110  -3.110  ...
...
```

**列说明**：
- 第1列：k点序号
- 第2列：k点距离（从起点累积，单位Å⁻¹）
- 第3列起：各条能带的能量（单位eV）

**提取带隙信息**：
```bash
grep -i "bandgap" OUT.Si/running_nscf.log
```

输出示例：`E_bandgap 0.5734 eV`

这就是Si的PBE带隙，约0.57 eV，远小于实验值1.17 eV。

## 5.2 能带图解读

### Si能带的关键特征

**价带与导带**：
- 费米能级（E=0）将能带分为价带（下方）和导带（上方）
- 价带：被电子占据的能带
- 导带：未被占据的能带

**间接带隙**：
- 价带顶：位于Γ点，能量约0 eV（费米能级）
- 导带底：位于Γ→X路径上，约0.85倍X点位置，能量约0.57 eV
- 带隙：~0.57 eV（PBE结果）

**能带色散**：
- Γ点附近：价带顶呈抛物线形，有效质量较小
- X点附近：导带底较平坦，有效质量较大
- L点：次高价带，能量略低于Γ点

## 5.3 带隙精度讨论

### Line 模式带隙的局限性

从 `running_nscf.log` 提取带隙：
```bash
grep -i "bandgap" OUT.Si/running_nscf.log
# 示例输出：E_bandgap  0.0630  0.8575
# 格式：第一列（Ry）第二列（eV）
```

> **⚠️ 重要提示**：Line 模式计算的带隙**仅供参考，不作为精确值**。

**原因分析**：

Si 是间接带隙半导体，导带底（CBM）位于 Γ→X 路径上的 Δ 点（约 0.85 × Γ→X 处）。Line 模式在该区间仅有十余个插值点，极易错过真正的最低点，导致带隙偏高。

**带隙精度对比**：

| 计算方法 | KPT 模式 | 典型结果 | 用途 |
|---------|---------|---------|------|
| NSCF + 均匀网格（15×15×15） | Gamma | **~0.57 eV** | 精确带隙 |
| NSCF + Line 路径（本案例） | Line | **0.7–0.9 eV** | 能带绘图 |
| 实验值 | - | **1.17 eV (300K)** | 参考 |

**结论**：
- Line 模式适合绘制能带图，展示能带色散关系
- 精确带隙需要用均匀 k 点网格的 NSCF 计算
- PBE 泛函的 0.57 eV 是系统性低估，并非计算错误

### 如何获得精确带隙

如需精确带隙，修改 NSCF 的 KPT 文件为密集均匀网格：

```
K_POINTS
0
Gamma
15 15 15 0 0 0
```

然后运行 NSCF（不输出能带文件）：
```bash
# 修改 INPUT：去掉 out_band 1，添加 out_bandgap 1
cp INPUT_nscf INPUT
cp KPT_dense KPT  # 使用密集网格
mpirun -np 8 abacus | tee nscf_dense.log
grep -i "bandgap" OUT.Si/running_nscf.log
```

此时得到的带隙约 0.57 eV，是 PBE 泛函的精确结果。

## 5.4 与实验值对比

**PBE vs 实验**：

| 项目 | PBE计算 | 实验值 |
|------|---------|--------|
| 带隙 | ~0.57 eV | 1.17 eV (300K) |
| 带隙类型 | 间接 | 间接 |
| 价带顶位置 | Γ点 | Γ点 |
| 导带底位置 | Γ→X路径 | Γ→X路径 |

**结论**：
- PBE低估带隙约50%，这是GGA泛函的已知局限
- 能带形状和色散关系与实验一致
- 间接带隙特征正确
- 对于定性分析和方法学习，PBE结果足够

# 第六章：参数优化与常见问题

## 6.1 常见问题与解决

### 问题1：找不到电荷密度文件

**错误信息**：
```
Can't find the file SPIN1_CHG.cube
```

**原因**：
- SCF未完成或失败
- 电荷密度文件被移动或删除
- `out_chg`未设置为1

**解决方法**：
- 检查SCF是否成功完成
- 确认`OUT.Si/SPIN1_CHG.cube`存在
- 如果文件在其他目录，在INPUT中设置`read_file_dir`

### 问题2：symmetry设置错误

**错误信息**：
```
Error in k-point symmetry operation
```

**原因**：
- NSCF使用Line模式但`symmetry = 1`

**解决方法**：
- 在INPUT_nscf中设置`symmetry = 0`

### 问题3：赝势文件名不匹配

**错误信息**：
```
Couldn't find pseudopotential file
```

**原因**：
- STRU文件中引用的赝势文件名与实际文件名不一致
- 常见情况：STRU中写`Si.upf`，但实际文件名为`Si_ONCV_PBE-1.0.upf`

**解决方法**：
1. 检查STRU文件中`ATOMIC_SPECIES`块的赝势文件名
2. 确认实际赝势文件的完整文件名（使用`ls *.upf`查看）
3. 修改STRU文件，使用完整的赝势文件名

**示例**：
```
# 错误写法
ATOMIC_SPECIES
Si 28.085500 Si.upf

# 正确写法
ATOMIC_SPECIES
Si 28.085500 Si_ONCV_PBE-1.0.upf
```

### 问题4：如何判断SCF是否收敛

**判断方法**：

1. **查看日志文件最后几行**：
```bash
tail -20 OUT.Si/running_scf.log
```

成功收敛会显示：
```
Total  Time  : 0 h 0 mins 30 secs
```

2. **检查收敛过程**：
```bash
grep "charge density" OUT.Si/running_scf.log
```

每步迭代的电荷密度变化应逐渐减小，最终小于`scf_thr`（如1e-08）

3. **查看warning.log**：
```bash
cat OUT.Si/warning.log
```

如果有严重错误会在此文件中显示

4. **确认输出文件存在**：
```bash
ls OUT.Si/SPIN1_CHG.cube  # SCF应生成此文件
```

**常见未收敛原因**：
- `scf_nmax`设置过小（默认100步通常足够）
- 初始结构不合理（原子距离过近）
- `mixing_beta`设置不当（默认0.8通常合适）

### 问题5：费米能级单位转换

**问题**：
- 旧版本ABACUS输出费米能级单位为Rydberg

**解决方法**：
- 检查输出单位
- 如果是Ry，乘以13.6058转换为eV
- 新版本（v3.0+）直接输出eV
