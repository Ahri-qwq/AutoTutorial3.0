# 第二章：Si体系准备

## 2.1 Si的晶体结构

### 金刚石结构

Si采用金刚石结构，这是一种面心立方（FCC）结构的变体。每个Si原子与4个最近邻原子形成共价键，键角109.5°（四面体角）。

**晶格参数**：
- 晶格常数：a = 5.43 Å（实验值，室温）
- 空间群：Fd-3m（No. 227）
- 原胞：2个Si原子
- 常规晶胞：8个Si原子

本教程使用8原子的常规晶胞，便于理解和可视化。

### 原子坐标

在立方晶胞中，8个Si原子的分数坐标为：
```
(0.00, 0.00, 0.00)  (0.25, 0.25, 0.25)
(0.00, 0.50, 0.50)  (0.25, 0.75, 0.75)
(0.50, 0.00, 0.50)  (0.75, 0.25, 0.75)
(0.50, 0.50, 0.00)  (0.75, 0.75, 0.25)
```

这8个原子构成了Si的金刚石结构。


## 2.2 STRU文件

STRU文件定义了晶体结构。以下是Si的完整STRU文件：

```
ATOMIC_SPECIES
Si 28.085500 Si.upf

NUMERICAL_ORBITAL
Si_gga_7au_100Ry_2s2p1d.orb

LATTICE_CONSTANT
1.889726  # Bohr to Angstrom conversion factor

LATTICE_VECTORS
5.43000000000  0.00000000000  0.00000000000
0.00000000000  5.43000000000  0.00000000000
0.00000000000  0.00000000000  5.43000000000

ATOMIC_POSITIONS
Cartesian  # 单位：Angstrom

Si
0.000000
8
0.00000000000  0.00000000000  0.00000000000  1 1 1
1.35750000000  1.35750000000  1.35750000000  1 1 1
0.00000000000  2.71500000000  2.71500000000  1 1 1
1.35750000000  4.07250000000  4.07250000000  1 1 1
2.71500000000  0.00000000000  2.71500000000  1 1 1
4.07250000000  1.35750000000  4.07250000000  1 1 1
2.71500000000  2.71500000000  0.00000000000  1 1 1
4.07250000000  4.07250000000  1.35750000000  1 1 1
```

**参数说明**：

- `ATOMIC_SPECIES`：元素符号、原子量、赝势文件名
- `NUMERICAL_ORBITAL`：数值原子轨道文件（本教程使用平面波，此行可省略）
- `LATTICE_CONSTANT`：晶格常数单位转换因子（1.889726 = 1 Bohr/Å）
- `LATTICE_VECTORS`：三个晶格矢量（单位：Å）
- `ATOMIC_POSITIONS`：原子坐标
  - `Cartesian`：笛卡尔坐标
  - `Si`：元素类型
  - `0.000000`：初始磁矩（非磁性体系设为0）
  - `8`：原子数量
  - 每行：x, y, z坐标 + 三个移动标志（1表示可移动，0表示固定）


## 2.3 赝势与基组

### 赝势文件

本教程使用ONCV赝势（Optimized Norm-Conserving Vanderbilt pseudopotential）：
- 文件名：`Si.upf` 或 `Si_ONCV_PBE-1.0.upf`
- 交换关联泛函：PBE
- 价电子：3s² 3p²（4个价电子）

赝势文件可从ABACUS官方仓库下载：
```
https://github.com/deepmodeling/abacus-develop/tree/develop/tests/PP_ORB
```

### 基组选择

本教程使用平面波基组（pw）：
- 优点：系统性收敛、无基组重叠误差
- 缺点：计算量较大
- 截断能：40 Ry（约544 eV）

**截断能说明**：
- 截断能决定平面波基组的大小
- 40 Ry对Si是合理的选择（已在第1篇教程中讨论收敛性）
- 更高的截断能提高精度但增加计算量

**注意**：虽然STRU文件中列出了`NUMERICAL_ORBITAL`（数值原子轨道），但由于INPUT中设置`basis_type = pw`，实际使用的是平面波基组，轨道文件不会被读取。

至此，Si体系的结构文件准备完毕，可以开始计算了。
