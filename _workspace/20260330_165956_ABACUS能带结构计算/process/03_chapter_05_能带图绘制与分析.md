# 第五章：能带图绘制与分析

## 5.1 使用abacus-plot绘图

### 准备config.json

进入输出目录并准备配置文件：

```bash
cd OUT.Si
cp ../KPT_nscf KPT
```

创建`config.json`文件：

```json
{
    "bandfile": "BANDS_1.dat",
    "efermi": 6.2345,
    "energy_range": [-6, 8],
    "kptfile": "KPT"
}
```

**参数说明**：
- `bandfile`：能带数据文件
- `efermi`：费米能级（从running_scf.log获取，单位eV）
- `energy_range`：能带图显示的能量范围（相对费米能级，单位eV）
- `kptfile`：KPT文件（用于标注高对称点）

### 运行abacus-plot

```bash
abacus-plot -b
```

输出文件：`band.png`

## 5.2 能带图解读

### Si能带的关键特征

**价带与导带**：
- 费米能级（E=0）将能带分为价带（下方）和导带（上方）
- 价带：被电子占据的能带
- 导带：未被占据的能带

**间接带隙**：
- 价带顶：位于Γ点，能量约0 eV（费米能级）
- 导带底：位于Γ→X路径上，约0.85倍X点位置，能量约0.57 eV
- 带隙：~0.57 eV（PBE结果）

**能带色散**：
- Γ点附近：价带顶呈抛物线形，有效质量较小
- X点附近：导带底较平坦，有效质量较大
- L点：次高价带，能量略低于Γ点

## 5.3 与实验值对比

**PBE vs 实验**：

| 项目 | PBE计算 | 实验值 |
|------|---------|--------|
| 带隙 | ~0.57 eV | 1.17 eV (300K) |
| 带隙类型 | 间接 | 间接 |
| 价带顶位置 | Γ点 | Γ点 |
| 导带底位置 | Γ→X路径 | Γ→X路径 |

**结论**：
- PBE低估带隙约50%，这是GGA泛函的已知局限
- 能带形状和色散关系与实验一致
- 间接带隙特征正确
- 对于定性分析和方法学习，PBE结果足够
