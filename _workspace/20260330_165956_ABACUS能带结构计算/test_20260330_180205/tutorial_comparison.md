## 核心差异

### 1. 基组选择 ⭐ 最大差异

**旧版（LCAO）：**
- 使用数值原子轨道基组
- 需要轨道文件：`Si_gga_8au_60Ry_2s2p1d.orb`
- `ecutwfc = 50 Ry`（控制电荷密度网格）
- 计算速度快，但需要轨道文件

**新版（PW）：**
- 使用平面波基组
- 不需要轨道文件
- `ecutwfc = 40 Ry`（控制平面波截断）
- 系统性收敛，无基组重叠误差

**影响：** 基组不同导致所有输入文件格式不同

### 2. 结构选择

**旧版：**
- 2原子原胞（FCC primitive cell）
- 晶格向量：$\frac{a}{2}[0,1,1]$, $\frac{a}{2}[1,0,1]$, $\frac{a}{2}[1,1,0]$
- K点：9×9×9 Gamma

**新版：**
- 8原子超胞（conventional cell）
- 晶格向量：立方，边长 5.43 Å
- K点：12×12×12 Gamma

**影响：** 超胞计算量更大，但结构更直观

### 3. 章节结构

**旧版（简洁型）：**
```
第一章：DOS 与能带结构（理论）
第二章：Si 能带计算案例（实战）
  2.1 体系说明
  2.2 输入文件准备
  2.3 运行计算
  2.4 费米能级提取
  2.5 abacus-plot 后处理
  2.6 结果解读
```

**新版（详细型）：**
```
第一章：认识能带结构（理论）
第二章：Si体系准备（结构文件）
第三章：SCF自洽计算（第一步）
第四章：NSCF能带计算（第二步）
第五章：能带图绘制与分析（后处理）
第六章：参数优化与常见问题（故障排除）
附录：参考资料、进阶学习
```

**影响：** 新版更详细，但篇幅更长

## 内容优劣势对比

### 旧版教程优势 ✅

1. **简洁高效**（328行 vs 862行）
   - 适合快速上手
   - 核心内容集中

2. **LCAO 基组实用性**
   - 计算速度快
   - 适合大体系
   - 培训环境常用

3. **带隙精度讨论详细** ⭐ 重要
   - 明确说明 Line 模式带隙不准确（0.7-0.9 eV）
   - 给出精确带隙值（0.57 eV，用均匀网格计算）
   - 解释为什么 Line 模式会高估带隙

4. **高对称路径更完整**
   - Γ-X-U-K-Γ-L-W-X（8点）
   - 覆盖更多布里渊区特征

5. **abacus-plot 配置详细**
   - 提供完整 config.json
   - 说明每个参数含义

### 新版教程优势 ✅

1. **结构更系统**
   - 6章分步讲解
   - 每步独立成章，逻辑清晰

2. **参数说明详细**
   - 每个 INPUT 参数都有注释
   - 区分 SCF 和 NSCF 的差异

3. **收敛判断详细** ⭐ 新增
   - 4种判断方法
   - 提供实际命令和输出示例
   - 列出常见未收敛原因

4. **故障排除完善** ⭐ 新增
   - 5个常见问题
   - 包含赝势文件名、收敛判断等实战问题

5. **平面波基组优势**
   - 系统性收敛
   - 无基组重叠误差
   - 不需要轨道文件

### 旧版教程劣势 ❌

1. **缺少收敛判断说明**
   - 只有一句"应出现：convergence is achieved"
   - 没有详细判断方法

2. **缺少故障排除**
   - 没有常见问题章节
   - 遇到错误无指导

3. **章节划分粗糙**
   - 所有实战内容挤在第二章
   - 2.2-2.6 小节跨度大

### 新版教程劣势 ❌

1. **篇幅过长**（862行）
   - 可能让初学者望而却步
   - 核心内容被稀释

2. **带隙精度讨论缺失** ⭐ 重要
   - 没有说明 Line 模式带隙不准确
   - 没有给出精确带隙参考值
   - 可能误导用户

3. **高对称路径较短**
   - L-Γ-X-U-K-Γ（6点）
   - 缺少 L-W-X 段

4. **abacus-plot 配置简略**
   - 没有完整 config.json 示例
   - 参数说明不够详细
