# 前言

本教程面向初次接触 ABACUS 的用户，目标是让读者在阅读完成后能够独立准备输入文件、运行一次 SCF 计算、并读懂输出结果。

**适用读者：** 具备基础密度泛函理论概念（知道 DFT 是什么即可），但尚未使用过 ABACUS 的用户。

**前置知识：**
- 密度泛函理论基本概念（Kohn-Sham 方程、交换关联泛函）
- 周期性边界条件和晶胞的概念
- 命令行基本操作

**教程结构：**
1. ABACUS 是什么 — 软件背景与功能定位
2. 运行一次计算需要什么 — 文件体系概述
3. INPUT 文件详解 — 控制计算行为的核心文件
4. STRU 文件详解 — 描述材料结构
5. KPT 文件详解 — 布里渊区 k 点采样
6. 计算结束后看什么 — 输出文件解读
7. 用 abacustest 提高效率 — 输入准备与结果抓取

本教程不涉及收敛性测试（截断能、k 点收敛）、能带结构计算、DOS 计算等进阶内容，这些将在后续教程中介绍。
