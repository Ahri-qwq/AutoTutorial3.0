# Step 2: 大纲方案

## Think Aloud

基于 Step 1 的调研结果，我设计了3个大纲方案：

**设计考虑：**
1. 覆盖用户要求的9个核心内容点
2. 避免与已有教程重复（不深入讲 ecutwfc 收敛测试、mixing 参数调优、弹性计算、能带/DOS 详细流程）
3. 目标读者：ABACUS 零基础新手
4. 全文长度：600-900 行（作为系列第一篇，需要打好基础）

**三个方案的差异：**
- 方案A：循序渐进型 - 从软件背景到文件格式，再到实战案例
- 方案B：快速上手型 - 先给完整案例，再逐个解释文件
- 方案C：参数分类型 - 按参数功能分类详细讲解

---

## 方案A：循序渐进型（推荐）

**特点：** 从理论到实践，适合零基础用户

**结构：**

### 前言（约40行）
- 教程目标：帮助新手快速上手 ABACUS
- 适用读者：第一性原理计算初学者
- 前置知识：基本的 Linux 命令、DFT 基础概念
- 教程结构：软件介绍 → 文件格式 → 参数详解 → 实战案例
- 后续篇章预告：力学性质、能带结构、态密度

### 第一章：ABACUS 软件简介（约80行）
- 1.1 软件背景与历史
  - 国产开源 DFT 软件
  - 开发团队与社区
  - 主要功能与特色
- 1.2 ABACUS 的核心能力
  - 支持的基组类型（PW/LCAO）
  - 支持的计算类型（SCF/relax/MD）
  - 高级功能简介（DFT+U、隐式溶剂等）
- 1.3 获取帮助的途径
  - 官方文档地址
  - GitHub 仓库
  - 社区支持

### 第二章：ABACUS 计算文件体系（约100行）
- 2.1 必需的三个文件
  - INPUT：计算参数控制
  - STRU：结构信息
  - KPT：k 点采样
- 2.2 可选的辅助文件
  - 赝势文件（.upf）
  - 轨道文件（.orb，LCAO 需要）
- 2.3 文件组织建议
  - 目录结构示例
  - 文件命名规范

### 第三章：STRU 结构文件详解（约120行）
- 3.1 文件格式说明
  - ATOMIC_SPECIES 块
  - NUMERICAL_ORBITAL 块（LCAO）
  - LATTICE_CONSTANT 和 LATTICE_VECTORS
  - ATOMIC_POSITIONS 块
- 3.2 坐标系选择
  - Direct（晶格坐标）
  - Cartesian（笛卡尔坐标）
- 3.3 完整示例：Si 晶体
  - PW 基组写法
  - LCAO 基组写法
- 3.4 常见问题
  - 赝势和轨道文件获取

### 第四章：KPT 文件详解（约80行）
- 4.1 布里渊区采样基础
  - k 点的物理意义
  - 采样密度与计算精度
- 4.2 KPT 文件格式
  - 自动生成模式（第2行为0）
  - Gamma 与 MP 方法
  - 网格参数与偏移
- 4.3 k 点设置建议
  - 不同晶系的选择
  - gamma_only 参数（大体系）
- 4.4 完整示例
  - 立方晶系（4×4×4）
  - 六方晶系（6×6×4）

### 第五章：INPUT 文件详解（约180行）
- 5.1 文件格式与基本规则
  - INPUT_PARAMETERS 开头
  - 注释规则（# 或 /）
  - 布尔值设置（1/0、True/False）
- 5.2 通用参数（必需参数）
  - suffix：输出后缀
  - ntype：元素种类数
  - pseudo_dir / orbital_dir：文件路径
  - calculation：计算类型（scf/relax/cell-relax/md）
  - basis_type：基组类型（pw/lcao）
- 5.3 精度控制参数
  - ecutwfc：平面波截断能（单位 Ry）
  - scf_thr：SCF 收敛阈值（单位 Ry）
  - scf_nmax：最大 SCF 步数
- 5.4 常用功能参数
  - smearing_method / smearing_sigma：能级展宽
  - symmetry：对称性开关（1/0/-1）
  - cal_force / cal_stress：力和应力计算
- 5.5 结构优化参数（relax/cell-relax）
  - force_thr_ev：力收敛阈值（eV/Å）
  - stress_thr：应力收敛阈值（kBar）
  - relax_nmax：最大优化步数
  - out_stru：输出优化结构
- 5.6 输出控制参数
  - out_chg：输出电荷密度
  - out_mul：输出 Mulliken 分析
- 5.7 完整示例：Si SCF 计算
  - PW 基组 INPUT
  - LCAO 基组 INPUT

### 第六章：结构优化实战（约100行）

  - 势能面与稳定构型
  - 力与应力的概念
- 6.2 relax 与 cell-relax 的区别
  - relax：固定晶胞优化原子位置
  - cell-relax：同时优化晶胞和原子位置
- 6.3 完整案例：MgO 晶体优化
  - 输入文件准备（INPUT/STRU/KPT）
  - 运行命令
  - 收敛判据说明
- 6.4 优化结果查看
  - STRU_ION_D 文件（优化轨迹）
  - 最终结构提取

### 第七章：输出文件解读（约120行）
- 7.1 输出文件结构
  - OUT.suffix/ 文件夹
  - time.json：计时信息
- 7.2 屏幕输出解读
  - 软件版本与编译信息
  - 输入参数回显
  - SCF 迭代过程（能量、电荷、磁矩）
  - 收敛判断
  - 总能量与费米能级
- 7.3 running_scf.log 文件
  - 详细的函数调用记录
  - 各模块耗时统计
- 7.4 关键物理量提取
  - 总能量（Total Energy）
  - 费米能级（Fermi Energy）
  - 力与应力（relax 计算）
- 7.5 常见警告与错误
  - SCF 不收敛
  - 内存不足
  - k 点设置不当

### 第八章：使用 abacustest 准备输入文件（约80行）
- 8.1 abacustest 简介
  - 功能概述
  - 安装方法（pip/源码）
- 8.2 准备输入文件
  - abacustest model inputs 命令
  - 从 CIF 文件生成 STRU
  - 自动设置基本参数
- 8.3 实战示例
  - 从材料数据库下载 CIF

  - 检查和修改参数

### 第九章：使用 abacustest 提取结果（约60行）

  - 总能量提取
  - 结构信息提取
  - 力和应力提取
- 9.3 简单示例
  - 提取 SCF 能量
  - 提取优化后结构
- 9.4 进阶功能预告
  - DOS/PDOS 绘图（详见后续教程）
  - 能带绘图（详见后续教程）

### 附录（约40行）

## 三个方案对比总结

| 维度 | 方案A（循序渐进） | 方案B（快速上手） | 方案C（参数分类） |
|------|------------------|------------------|------------------|
| 适合读者 | 零基础新手 | 动手型学习者 | 需要查阅参考 |
| 学习曲线 | 平缓 | 陡峭但快速 | 中等 |
| 实战案例 | 分散在各章 | 集中且丰富 | 集中在后面 |
| 系统性 | 强 | 中等 | 最强 |
| 可读性 | 最好 | 好 | 中等 |
| 篇幅 | 约1000行 | 约940行 | 约920行 |

**我的推荐：方案A（循序渐进型）**

**理由：**
1. 作为系列第一篇，需要为零基础用户打好基础
2. 结构清晰，逻辑连贯，适合从头到尾阅读
3. 覆盖所有9个核心内容点，且避免了与后续教程重复
4. 虽然篇幅稍长，但作为入门教程是合理的
