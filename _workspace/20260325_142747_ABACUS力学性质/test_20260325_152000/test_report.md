### 非正常情况处理

1. **RelaxPlugin SKIP（预期内）**：教程含 h-BN cell-relax 内容，触发了 RelaxPlugin，但 h-BN 原子坐标不完整 + B/N 赝势无法下载，导致准备失败。已在 `test_framework_integrated.py` 中添加 try-except，框架正常跳过，不影响 ElasticPlugin 流程。

2. **case_name 解析为"中"**：`_extract_case_name` 的正则未能正确提取 "Si"，最终目录名为 `中_elastic/`。已手动在该目录下操作，不影响计算结果。（建议后续修复正则）

3. **输入文件手动修复**：
   - STRU 中 `Si_ONCV_PBE-1.2.upf` → `Si_ONCV_PBE-1.0.upf`（本地缓存版本）
   - STRU 中 `Si_gga_8au_60Ry_2s2p1d.orb` → `Si_gga_8au_100Ry_2s2p1d.orb`（本地缓存版本）
   - 移除 ATOMIC_SPECIES 中废弃字段 `upf201`
   - INPUT 中移除 `fixed_axes None` 和行内注释（ABACUS 解析问题）

4. **elastic post 路径调整**：将 Bohrium 下载的 OUT.ABACUS 结果从 `results/deformed_XX/` 复制回 `deformed_XX/OUT.ABACUS/`，再执行 `abacustest model elastic post -j .`。
