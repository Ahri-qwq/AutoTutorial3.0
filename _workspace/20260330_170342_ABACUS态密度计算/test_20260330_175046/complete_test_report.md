## 发现并修复的问题

### 1. INPUT 文件配置错误

**问题**: 测试框架为所有计算类型生成了相同的 INPUT 模板
- relax 目录使用了 `calculation = scf`
- 所有目录都包含 `init_chg = file` 和 `out_dos = 2`

**修复**:
- relax: 改为 `calculation = relax`，删除 init_chg 和 out_dos
- nscf: 改为 `calculation = nscf`，保留 init_chg
- mat1_scf: 删除 init_chg 和 out_dos

### 2. STRU 文件赝势文件名不匹配

**问题**: 教程使用 `Mg.PD04.PBE.UPF`, `O.upf`，实际为 `Mg_ONCV_PBE-1.0.upf`, `O_ONCV_PBE-1.0.upf`

**修复**: 批量更新所有 STRU 文件

### 3. 轨道文件名映射

**问题**: `O_gga_6au_100Ry_2s2p1d.orb` → `O_gga_7au_100Ry_2s2p1d.orb`

**修复**: 测试框架自动处理

### 4. NSCF 电荷密度文件位置

**问题**: 电荷密度文件需要在 OUT.ABACUS 目录

**修复**: 创建 OUT.ABACUS 并复制文件
