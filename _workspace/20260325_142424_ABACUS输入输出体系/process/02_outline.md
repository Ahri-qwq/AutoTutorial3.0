# Step 2 大纲方案

## 背景分析

**教程需覆盖的5个子主题**（来自用户需求）：
1. INPUT 参数详解 + SCF 收敛算法参数（mixing_type/mixing_beta）
2. KPT 采样策略（MP 网格 + 路径 KPT，Al 收敛测试案例）
3. STRU 结构文件定义（PW + LCAO 两种写法）
4. 平面波截断能收敛测试（ecutwfc，Al 案例）

**长度目标**：参考文章均值 345行/883 words，本教程内容约为3-4篇参考文章的等效量，目标700-1000行。

---

## 方案A：参考手册型

**定位**：系统化参考手册，每个文件独立一章，适合想查询某类参数的用户。

```
# ABACUS 输入文件详解：INPUT / STRU / KPT

一、STRU：结构文件（约150行）
  1.1 整体结构
  1.2 各部分说明（ATOMIC_SPECIES / LATTICE / ATOMIC_POSITIONS）
  1.3 PW写法 vs LCAO写法

二、KPT：k点文件（约150行）
  2.1 MP 网格格式
  2.2 线路 k 点格式（能带计算）
  2.3 Al k 点收敛测试

三、INPUT：计算参数文件（约250行）
  3.1 基本参数
  3.2 SCF参数（scf_thr / scf_nmax）
  3.3 电荷密度混合（mixing_type / mixing_beta）
  3.4 Smearing 参数
  3.5 平面波截断能（ecutwfc）+ Al收敛测试

附录：输出文件概览（约50行）
```

**优点**：结构清晰，各文件独立，适合查阅参考
**缺点**：没有主线案例贯穿，读者难以感受"完整跑一次计算"的体验
**全文估计**：约620行

---

## 方案B：流程贯穿型（推荐）

**定位**：以"从零到运行出总能量"为主线，先介绍三文件，再做收敛测试。Al FCC 是全文主角，收敛测试作为进阶验证章节。

```
# ABACUS 输入输出体系：三文件入门与收敛性测试

一、引言（约30行）
  - 三文件角色简介

二、STRU：晶体结构文件（约180行）
  2.1 文件整体结构与必选块
  2.2 逐块详解（ATOMIC_SPECIES / LATTICE_CONSTANT / LATTICE_VECTORS / ATOMIC_POSITIONS）
  2.3 PW 写法（Al，无 NUMERICAL_ORBITAL）
  2.4 LCAO 写法（Al，加 NUMERICAL_ORBITAL）

三、KPT：布里渊区 k 点（约160行）
  3.1 MP 网格（自洽计算用）
  3.2 路径 k 点（能带计算用）
  3.3 Al k 点收敛测试

四、INPUT：计算控制参数（约250行）
  4.1 文件语法与注意事项
  4.2 计算类型（calculation）与基本参数
  4.3 SCF 迭代控制（scf_nmax / scf_thr）
  4.4 展宽参数（smearing）
  4.5 电荷密度混合（mixing_type / mixing_beta / mixing_gg0）
  4.6 平面波截断能（ecutwfc）+ Al 收敛测试

五、总结（约40行）
  - 参数速查表

附录：输出文件概览（约60行）
```

**优点**：以实际操作顺序组织，读者边学边建立心智模型；收敛测试自然嵌入 ecutwfc 小节
**缺点**：INPUT章节略长（但ecutwfc + mixing内容确实较多）
**全文估计**：约720行

## 方案C：收敛测试驱动型

**定位**：以"如何做对一个 Al SCF 计算"为问题驱动，先把三文件拼好跑起来，再通过收敛测试验证参数选择。

```
# ABACUS 计算入门：三文件准备与参数收敛测试

一、引言（约30行）
  - 什么是三文件 / 为什么要做收敛测试

二、快速搭建第一个计算（约200行）
  2.1 STRU：Al FCC 结构（PW写法）
  2.2 KPT：选好 k 网格
  2.3 INPUT：最小化配置跑出 SCF

三、收敛性测试（约350行）
  3.1 ecutwfc 收敛测试（Al数据 + 脚本）
  3.2 k 点收敛测试（Al数据 + 脚本）
  3.3 mixing 参数调整策略

四、LCAO 与 PW 的区别（约120行）
  4.1 STRU 的 NUMERICAL_ORBITAL 块
  4.2 INPUT 中 basis_type 的影响
  4.3 路径 k 点（能带计算专用格式）

五、参数速查与常见问题（约80行）

附录：输出文件概览
```

**优点**：问题导向，有实战感，适合初学者"动手边学"
**缺点**：INPUT参数讲解不够系统完整，参数分组逻辑散落在各章；STRU/KPT详解偏弱
**全文估计**：约800行
